# Reports

This folder holds the TXT reports exported from the officer's Reports menu.

Files are replaced when the same report is exported again.

| File | Contents |
|------|----------|
| placement_report.txt | Complete placement report with statistics |
| student_report.txt | All students with CGPA, backlogs, and status |
| company_report.txt | All companies with HR contacts |
| job_report.txt | All jobs with eligibility criteria |
| application_report.txt | All applications with status |
| interview_report.txt | All interview rounds and results |
| placement_list.txt | Every placement record |
| department_report.txt | Department-wise placement counts and rates |
| company_wise_report.txt | Placements per company |
| package_report.txt | Highest, lowest, and average package |

Student resumes exported from the student portal are saved here as `resume_<studentId>.txt`.

Do not edit these files by hand. Regenerate them from the program instead.
